Project Gutenberg: System Evaluation

Context

Project Gutenberg's mission is to "encourage the creation and distribution of eBooks" digitizing literature so that is available for free to the public. Project Gutenberg was started by Michael Hart in 1971. Since then, it has become an online library of more than 75,000 free eBooks!

Content

Project Gutenberg gives users access to public domain eBooks. These books are digitized and sorted by volunteers. Their range of content is massive, and they feature different genres, languages, and age ranges. You can find classic literature, how-to books, and even reference materials!

Metadata and other information on the books:

  • Author
  • Title
  • Notes and Fun Facts
  • Credits
  • Reading Level
  • Language
  • LoC Class
  • Subject
  • Category
  • eBook-No.
  • ISBN (HTML)
  • Release Date
  • Last Update
  • Copyright status
  • Download number in the last 30 days
  • Book Description
  • Cover Art
  • Reader's Advisory Recommendations

Users

Project Gutenberg is for readers of all types with access to technology. You can find books on physiology and German children's books all on the same website, so many different users can find what they need on this website. That being said, the search function leaves something to be desired. It is difficult to narrow down results from a keyword search due to the lack of filters available in the quick-search function. The advanced search allows you to be a bit more precise, but it lacks the structure of a system like Primo.

Discussion

Project Gutenberg uses Plain Vanilla ASCII. This means the PG files can be read, indexed, and processed by a wide variety of devices, operating systems, or programming languages.

I would improve upon the search function. I believe a more involved database search including boolean operators and keywords would help people find books without already knowing the name or the title. Currently, it would be hard to browse books without having a solid sense of direction ahead of time.

Pros Cons
  • All of the eBooks are free and open to the public!
  • Uses variety of basic formats (plain text, HTML, & EPUB)
  • It is volunteer-run, so there are no ads
  • Collection is limited to works in the public domain
  • Basic sorting, searching, and use of metadata
  • Number of books available makes it overwhelming to browse
